## `~/principles`

```diff
+ Read more code than you write.
- Treat reading production code as a chore.
# The engineers who compound fastest are the ones who do this every day.

+ Optimize for clarity, then for cleverness.
- Show off in code you'll re-read in six months.
# Future-you is the most frequent reader of your work. Be kind to them.

+ The fundamentals compound.
- Chase the framework of the week.
# Pointers, recursion, and trade-offs outlast every JS framework cycle.

+ Ship → measure → iterate.
- Polish in private for months.
# A rough thing in production teaches more than a perfect thing in a branch.
```
